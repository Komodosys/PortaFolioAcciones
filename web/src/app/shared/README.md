# `shared` — piezas reutilizables

Componentes, directivas y utilidades que usan **dos o más** funcionalidades: formateadores de importes
y fechas, indicadores de frescura del precio, diálogos, etc.

Regla: aquí no hay lógica de negocio. Un formateador de importes sí; el cálculo de una ganancia, no
(eso vive en el backend).
